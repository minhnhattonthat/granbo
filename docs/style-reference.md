# Style reference

Approved voice samples from the pilot batch (b006, the opening at Old Gen's house). Match these.

| Character | Voice | Example (JP gist -> EN) |
|---|---|---|
| Old Gen (Genzo) | gruff, warm, old-fashioned; じゃ/のう endings -> folksy phrasing, "Bah!", "Hmm-hm", laughs "Kakakaka!" | この大バカ者っ！！ -> "You great big fool!!" / カッカッカッカッカ -> "Kakakakaka!" |
| Shizuku | polite, gentle, keeps people at a distance | これは私のモンダイなのですから -> "This is my problem..." |
| Townsfolk | plain, friendly | ここはグランボセイバーがあつまる... -> "This is the Saver Station, where Granbo Savers gather!" |
| Narration ({9201} pages, no speaker) | short, past tense or present, neutral | ゲンじいといっしょに出かける事になった！！ -> "You set out with Old Gen!!" |
